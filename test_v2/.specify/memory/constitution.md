# spec-kit Constitution

## Core Principles

### I. 方法論：嚴格 SDD
所有開發工作必須嚴格遵循規格驅動開發（Specification-Driven Development）的流程。

### II. 範疇：僅限前端
開發範疇僅限於前端 UI 與組件邏輯，以 MVP (Minimum Viable Product) 為目標。

### III. 語言：僅限繁體中文
所有描述性內容，包含程式碼註解，都必須使用繁體中文。

### IV. 技術棧：僅限 HTML、CSS、Javascripts
僅能使用 HTML、CSS 和 JavaScript，不得安裝任何額外的程式套件。

### V. 資料：使用 JSON 儲存於前端
所有資料都必須使用 JSON 格式儲存於前端。

## Governance

本憲章效力高於所有其他實踐。任何修訂都必須經過文件記錄、審核及遷移計畫。
